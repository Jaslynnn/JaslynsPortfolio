# public/images/gloo-tooling

Card image for the "Gloo Communications Tooling" project.

- Drop the file here and name it **`card.jpg`** (or `card.png` / `card.webp`).
- Any size works; it's shown at a 16:9 crop-safe area with `object-contain`,
  so a wide-ish image looks best. ~1600×900 is plenty.
- Extra images (screenshots for the pop-up later) can go in this same folder
  with any name.

Then tell Claude, or set it yourself in `content/work/gloo-tooling.ts`:

```ts
images: ["/images/gloo-tooling/card.jpg"],
```
